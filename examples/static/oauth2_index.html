OAuth2 Sample Server

Authorization Code Flow

1. Start the flow by clicking the button below. You will be redirected to Login, then Consent, then back to the Callback URL with a code.

Client ID: nav_public_client (public — PKCE S256 required)

Redirect URI: http://localhost:5000/static/callback.html

This page starts the flow without PKCE, so the exchange will be rejected with invalid_grant: PKCE required for public clients. That is the correct behaviour for a public client — see examples/oauth2_3lo_server.py for the complete flow with PKCE.

Client Credentials Flow

Use curl to test:

curl -X POST http://localhost:5000/oauth2/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials&client_id=nav_confidential_client&client_secret=confidential_s3cr3t"

Setup

The clients above are registered on startup by examples/oauth2_server.py in the in-memory client storage (OAUTH2_CLIENT_STORAGE=memory).
