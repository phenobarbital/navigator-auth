navigator-auth · OAuth2 3LO

Authorization Code + PKCE against this same aiohttp server, then one call to GET /api/v1/me — an endpoint protected with @is_authenticated() and @user_session().

The flow

  1. PKCE — the page generates a code_verifier and its S256 code_challenge.
  2. Authorize — the browser goes to /oauth2/authorize, logs in and approves the consent screen.
  3. Callback — navigator-auth redirects back here with ?code=…&state=….
  4. Token — the page exchanges the code at /oauth2/token with the code_verifier.
  5. Resource — it calls /api/v1/me with Authorization: Bearer ….
